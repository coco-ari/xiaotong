# 日系抽象色面人物卡面

## 适用边界

- 适合：具有独立透明角色的陪伴首页；按数据状态切换的角色卡面；以内容为主的轻量手机界面。
- 避免：用装饰文字代替业务内容；在背景中加入具象物件；把复杂细节放进文字安全区；用背景单图判断完整首页质量。
- 实现成本：中；需要独立生成情绪背景、与透明人物合成检查，并验证实际文字与图片加载。

## 验收条件

- 在 320px、393px 与桌面宽度实际叠加人物，标题不侵入人物区域。
- 长文字、四行短句、正负金额和数据缺失状态仍可读；夜间浅色字有足够对比。
- 六种背景仅由抽象色面与曲线组成，不包含具象物件、人物或业务文字。
- 浏览器检查图片资源可用、切换无双人物和页面横向溢出，减少动态效果可用。
