# 从截图到真实操作的验收

分类：可用性 · 标签：验收、无障碍、回归 · 推荐 · 主观评分：9.4/10 · 整理：2026-10-13

把审美主张转成可观察结果，能识别截图无法暴露的交互缺陷。

## 适用边界

- 适合：发布前检查；UI 仓库条目审核；新组件验收。
- 避免：axe 零问题即宣称全面认证；只测试宽屏默认态；截图漂亮即判完成。
- 实现成本：中；重点流程浏览器检查。

## 可复制提示词

~~~~text
为这次 UI 变更制定与范围相称的验收：先走核心用户路径，再检查桌面、窄屏、长中文、空数据、接口失败与加载。验证 Tab 焦点顺序、原生控件键盘操作、弹窗关闭恢复、触摸命中、快速反向操作和减少动态效果。静态截图检查层级、边界、截断和对比，浏览器操作检查真实状态与数据；自动工具只辅助发现问题，不替代人工判断。按位置修复真正的问题，记录通过项、工具发现和尚未覆盖的条件，不虚构用户测试或转化率提升。
~~~~
