# 几何与光学细节的最后一轮打磨

分类：设计系统 · 标签：对齐、圆角、细节 · 推荐 · 主观评分：8.9/10 · 整理：2026-10-13

细小的一致性容易积累成质感，而且通常比增加动画更经济。

## 适用边界

- 适合：发布前精修；组件一致性；有既定视觉方向的产品。
- 避免：不解决任务却只调阴影；为了变化反复换字体。
- 实现成本：低到中；逐组件核对。

## 可复制提示词

~~~~text
在现有设计方向上做最后一轮精修：比较相邻卡片的内边距、标题基线、图标线宽和文字粗细；数字使用等宽字形。嵌套圆角随内边距自然递减，阴影只表达层级，细分割线组织内容。图标与文字按视觉中心校正，但不缩小触控命中范围。逐项检查默认、悬停、聚焦、按下、禁用、加载与错误，不用 transition-all。先用静态截图发现对齐问题，再用真实点击和键盘验证；只有能说明收益的差异才修改。
~~~~

## 验收条件

- 同级卡片和按钮的间距与圆角有统一依据。
- 图标视觉对齐不改变可操作区域。
- 状态切换不造成文字宽度或容器位置抖动。
