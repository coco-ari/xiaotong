# 图片缩略图到详情的连续展开

分类：交互动效 · 标签：共享元素、图片、预览 · 有条件 · 主观评分：8.6/10 · 整理：2026-10-13

源图与详情关系明确时有价值，适合未来素材库而非所有卡片。

## 适用边界

- 适合：背景素材预览；角色立绘查看；UI 参考缩略图。
- 避免：只为文本详情硬做形变；跨比例图像拉伸；未加载原图先放大空框。
- 实现成本：中到高；图片解码、焦点与滚动状态。

## 可复制提示词

~~~~text
为素材缩略图增加可访问的大图预览。点击后先确认原图解码可用，保留原缩略图占位，在约 240ms 内建立从缩略图到预览图的连续关系；图像始终保持纵横比，不把文字和整个卡片一起拉伸。预览作为有名称的 dialog，锁定背景操作，支持 Esc、可见关闭按钮和焦点返回，保留打开前滚动位置。窄屏优先保证完整图像和关闭控件可达。连续打开不同图时清理上一张过渡；图片失败保留缩略图并显示重试。减少动态效果直接打开。

减少动态效果：无空间移动，直接打开详情或淡入。

上述数值为项目起始参数，应结合真实设备调整；不增加与当前任务无关的效果。
~~~~

## 验收条件

- 大图始终保持比例，横图和竖图均不变形。
- 关闭后仍在原浏览位置和原触发器。
- 慢网、失败、快速换图不会闪白或出现两个焦点目标。
