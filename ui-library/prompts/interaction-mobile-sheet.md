# 有滚动边界的手势抽屉增强

分类：交互动效 · 标签：抽屉、触摸、阅读 · 有条件 · 主观评分：8.7/10 · 整理：2026-10-13

在可靠原生弹窗基础上，确有移动手势需求时再添加拖拽；基础弹窗与手势增强分开评估，避免把普通底部布局误称为已实现手势。

## 适用边界

- 适合：手机文章详情；筛选面板；短设置。
- 避免：长表单任意拖拽关闭；未保存编辑丢失；正文滚动触发关闭。
- 实现成本：高；软键盘、滚动、焦点及手势协同。

## 可复制提示词

~~~~text
仅在手机视图将短设置或只读详情显示为底部抽屉，保留可见关闭按钮、标题和遮罩；桌面保留适合的面板。面板约 220ms 进入，打开即建立正确焦点范围和背景不可操作状态，关闭恢复触发器焦点。拖拽只能从明确手柄开始，正文照常滚动；手势取消回到当前状态，不能误关闭未保存编辑。尊重系统返回与 Esc，输入时检测可用视口，确保软键盘不挡确认按钮。优先完成按钮关闭与滚动后再增强拖拽。减少动态效果取消位移和背景缩放。

减少动态效果：抽屉直接出现或淡入；禁用背景缩放与惯性装饰。

上述数值为项目起始参数，应结合真实设备调整；不增加与当前任务无关的效果。
~~~~

## 验收条件

- 手机长正文滚动不误触关闭。
- 打开软键盘后输入与确认按钮都可达。
- 未保存信息不会被轻扫直接丢弃；Esc 与关闭按钮均可用。
