# 可信的数字更新

分类：交互动效 · 标签：指标、NumberFlow、等宽数字 · 推荐 · 主观评分：9.4/10 · 整理：2026-10-13

保留数字精确读数，并用小幅变化提示数据更新。

## 适用边界

- 适合：收藏数量；待办数量；低频汇总指标。
- 避免：首次从零滚到资产金额；高频行情每次全列翻滚；用数字动画暗示虚假趋势。
- 实现成本：低；复用现有 @number-flow/react。

## 可复制提示词

~~~~text
使用现有 NumberFlow 优化少量汇总数字，只在真实数据变化时短暂过渡。首次加载立即显示最终数值，不从零计数；输入与财务精确核对期间关闭滚动。统一 Intl 数字格式、正负号、单位和小数位，使用 tabular-nums 与稳定宽度避免卡片抖动。更新方向由真实数据决定，不为装饰统一向上滚；涨跌同时用文字或符号表达。加载、未知、错误与数值零明确区分。约 220ms 作为起始动画预算，减少动态效果使用 animated=false 或默认偏好机制；快速新值到达直接以最新值为准。

减少动态效果：保留默认尊重用户偏好，直接显示最终值。

上述数值为项目起始参数，应结合真实设备调整；不增加与当前任务无关的效果。
~~~~

## 验收条件

- 0、未知、加载失败呈现不同状态。
- 负数、较长金额与小数更新不挤压相邻标签。
- 首次加载无误导性零值，关闭动态效果仍显示精确值。
