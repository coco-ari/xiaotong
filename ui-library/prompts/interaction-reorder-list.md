# 带明确手柄的列表重排

分类：交互动效 · 标签：拖动、排序、收藏 · 有条件 · 主观评分：8.7/10 · 整理：2026-10-13

有真实排序需求时，位置过渡能预告放置结果；不应为演示额外创造任务。

## 适用边界

- 适合：用户自定义收藏顺序；可编辑快捷入口。
- 避免：系统排名列表；只读行情列表；没有持久化的假拖动。
- 实现成本：高；指针、键盘、持久化和回滚。

## 可复制提示词

~~~~text
为允许自定义顺序的列表增加独立拖动手柄，文本、链接和收藏按钮保持正常点击行为。拖动时保持占位和原始尺寸，仅当前项略升起，其他项用短位置过渡预告落点；拖拽中不让文字缩放变形。触摸仅在手柄上启动，列表本身照常滚动。提供“上移／下移”键盘可用操作与位置播报，不依赖拖动完成任务。放下后持久化真实顺序，失败回滚并提示；按 Esc 可取消当前拖动。稳定 key 与数据 id 对应，减少动态效果直接改变位置。

减少动态效果：排序立即更新，保留明确位置提示。

上述数值为项目起始参数，应结合真实设备调整；不增加与当前任务无关的效果。
~~~~

## 验收条件

- 关闭页面重开后用户顺序保留。
- 保存失败恢复原顺序，删除或过滤不使 id 错位。
- 不使用鼠标也能完成同样的排序任务。
