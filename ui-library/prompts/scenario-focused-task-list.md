# 让下一件事明确的计划列表

分类：场景方案 · 标签：待办、行动层级、完整状态 · 推荐 · 主观评分：8.8/10 · 整理：2026-10-13

这是可复用于未来模块的任务方案，不假称当前项目已经实现计划管理。

## 适用边界

- 适合：未来计划模块；习惯清单；个人任务面板。
- 避免：把任务藏在装饰卡片里；所有按钮同样突出；用动效冒充完成状态。
- 实现成本：中；需真实任务数据与持久化接口。

## 可复制提示词

~~~~text
为个人计划模块设计一个以“下一件事”为中心的列表。任务标题、时间和完成状态清楚可扫，主操作可见，低频编辑放明确菜单。只有真正存在的字段才显示；无计划时给出可执行的新增入口，加载时保持布局，保存失败保留输入并支持重试。完成状态必须来自实际保存结果，文字和图标同时表达，允许合理撤销。键盘可创建、切换完成并编辑，触摸范围清晰；先实现稳定顺序，用户明确需要时再加入带手柄和键盘替代的重排。配色沿用角色品牌，任务区域保持安静。
~~~~

## 验收条件

- 可以完成新增、完成、编辑和失败恢复闭环。
- 无任务、加载和错误不会混成同一空白。
- 鼠标、键盘和触摸具有等价主要能力。
