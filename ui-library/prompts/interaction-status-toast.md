# 可读且可撤销的操作反馈

分类：可用性 · 标签：Toast、复制、收藏、撤销 · 推荐 · 主观评分：9.6/10 · 整理：2026-10-13

真实结果反馈可避免重复点击；撤销、堆叠及暂停计时是额外能力。本轮收藏已有即时状态反馈，完整可撤销通知模式保留为候选。

## 适用边界

- 适合：复制提示词；收藏成功；保存设置；可逆移除。
- 避免：重大错误只闪现几秒；一条操作触发多条提示；把 toast 当唯一数据状态。
- 实现成本：中；统一状态组件与计时逻辑。

## 可复制提示词

~~~~text
建立统一操作提示，区分进行中、成功、失败；同一操作用同一条消息更新，保持信息简短明确。底部或角落固定提示区避免覆盖主要导航；新提示约 160ms 淡入，可中断和更新，最多展示少量消息。复制成功必须在 Clipboard API 实际成功后出现，失败给手动复制入口。可逆移除显示“撤销”按钮并真实恢复数据；重要错误保持到用户处理。消息不抢焦点，普通结果用礼貌播报；悬停、键盘聚焦或页面隐藏时暂停自动消失计时。保留关闭按钮与触摸可达性，减少动态效果时不位移。

减少动态效果：用静态出现或轻淡入，去掉位移堆叠。
~~~~

## 验收条件

- 系统剪贴板失败不会显示成功。
- 焦点进入提示操作后消息不会突然消失。
- 页面切后台再回来仍能看到尚未读完的结果。
