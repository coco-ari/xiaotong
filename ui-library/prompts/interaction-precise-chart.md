# 精确图表检查与结构化替代

分类：可用性 · 标签：图表、财务、无障碍 · 推荐 · 主观评分：9.6/10 · 整理：2026-10-13

实时读值与结构化替代使趋势图可信。本轮详情页已采用原生滑杆实时读值，完整数据表和逐点图形键盘检查仍是后续候选，因此本条不标为整体已应用。

## 适用边界

- 适合：财务趋势；历史统计；计划完成率。
- 避免：弹簧追随十字线；缓动改变准确数据点；只有颜色区分系列。
- 实现成本：中；语义摘要、数据表与输入支持。

## 验收条件

- 同一数据点在悬停、触摸和表格里的数值一致。
- 全部关键结论能通过文字或结构化表格获取。
- 空数据、单点、负值和接口错误都有可读状态。
