# 小彤 UI 提示词仓库

这里保存经过来源查证、场景评价与本项目改写的 UI 提示词。目标是让下一次改界面时，可以选择有明确用途、实现边界和验收条件的规格，而不是反复要求模型“做得高级一点”。

当前版本整理于 **2026-10-13**：30 条原创提示词、55 条来源评审、52 个唯一 URL、31 个同源作者／机构族。50 条评审已读取正文或明确范围，对应 47 个唯一 URL、27 个来源族。其余记录保留受阻或排除原因，不作为推荐依据。**这些数字不代表找到了 55 个独立、热门、完整验证过的方案。**

## 选择和使用

1. 从项目「设置 → 设计提示词库」进入，按设计系统、交互动效、可用性、场景方案筛选，也可以搜索标签与适用场景。
2. 先读“适合”“避免”“为什么”和成本，再复制完整提示词。提示词中的触发条件、状态反馈、键盘操作和减少动态效果要求应一并保留。
3. 把目标页面、真实数据、现有组件和产品约束提供给模型。每次优先解决一个具体问题；多个效果之间有冲突时，先维持任务连续性和内容清晰度。
4. 实现后按验收条件检查，再把确实应用的文件写入 `appliedTo`。需要限定范围时补充 `applicationScope`。候选规格与实际实现必须分开记录。

本轮有 11 条提示词标注了应用文件；这表示相应模式或注明的部分已落地，不表示全部提示词、设备与无障碍标准都已验证。具体取舍见 [DECISIONS.md](DECISIONS.md)，本轮应用与浏览器检查见 [验收记录](../docs/design/ui-refactor-validation.md)。

网页通过 HTTP 服务加载 `catalog.json`，直接双击 HTML 的 `file://` 地址可能无法读取数据。运行开发服务后，可从项目入口访问 UI 仓库；正式构建会一并发布静态仓库页面。页面源文件位于 [site/index.html](site/index.html)。

## 文件组织

| 文件 | 用途 | 是否直接修改 |
| --- | --- | --- |
| [catalog.json](catalog.json) | 来源评审、原创提示词、统计和应用映射的唯一数据源 | 是 |
| [DECISIONS.md](DECISIONS.md) | 评分方法、项目适配、未采用效果和实现边界 | 是 |
| `site/index.html`、`site/library.css`、`site/library.js` | 可搜索、筛选、复制的网页源文件 | 是 |
| `prompts/*.md` | 每条提示词的独立文档，适合代码评审和直接阅读 | 否，由脚本生成 |
| `prompts/.generated.json` | 自动生成文件清单，用于安全清理旧产物 | 否 |
| `../public/ui-library/` | 网页资源和目录数据的发布副本 | 否，由脚本生成 |
| [../scripts/build-ui-library.mjs](../scripts/build-ui-library.mjs) | 数据校验与发布脚本 | 是 |

## 更新与校验

只检查数据、引用和已应用文件，不写生成产物：

```sh
npm run ui:check
```

校验并重新生成 Markdown 与网页发布副本：

```sh
node scripts/build-ui-library.mjs
```

`npm run build` 的 `prebuild` 会自动执行生成脚本。脚本不会修改 `catalog.json` 或 `site/` 源文件；只删除旧清单中带有本脚本生成标记的 Markdown，遇到同名人工文件会报错，不会覆盖。

维护时请遵循以下顺序：

1. 实际打开来源，填写直接 URL、作者、阅读范围、查证日期和复用边界。仅搜索到摘要、正文受阻、只读了部分文件，应分别如实记录。
2. 将同一仓库、同作者系列文章及其相关推广讨论归入同一个 `sourceFamily`。同 URL 的不同样式可以分别评审，但不能被计成多个唯一来源地址。
3. 写出优点、限制和适用／不适用场景。热度单独记录证据与层级，不把仓库总星数当成某个子技能安装量，也不把作者自述当作独立验证。
4. 用本项目语言原创改写提示词，补齐状态、失败或减少动态效果回退、验收条件和实现成本。不要搬运完整第三方技能、付费内容或未经授权的代码。
5. 更新 `meta` 中的真实统计，再运行 `npm run ui:check`。校验会拒绝重复 ID、不存在的引用、不安全路径、失真的计数、评分越界，以及使用待读或排除来源支持推荐的条目。

## 评价含义

评分是本轮 0–10 分主观判断，综合任务适配、可执行性、交互边界、可访问性与复用清晰度，不是行业排名、用户研究或模型基准。推荐提示词至少 8 分，有条件收录至少 7 分。来源记录允许低分和排除项，以保留取舍证据；待读的 0 分只是字段占位，不是质量零分。

`evidenceStatus` 区分已读、部分已读、仅搜索摘要和受阻。`independentSourceCount` 为兼容页面数据接口保留该名称，实际统计的是 `sourceFamily` 数量，不能解释为独立研究或独立实验证据。统计与每条来源的阅读范围应同时阅读。

来源关联表示借鉴了相应原则，不表示原作者写过、认可或担保本库提示词。全部热度快照和内容判断均可能随来源更新而变化，后续维护应重新查证。
