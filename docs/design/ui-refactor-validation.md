# 提示词库与界面重构验收

日期：2026-10-13。入口：应用内「设置 → 设计提示词库」。研究方法、原始链接和评分见 [UI 仓库](../../ui-library/README.md)，具体采用理由见 [设计取舍](../../ui-library/DECISIONS.md)。

## 已完成的界面变化

- 暖墨画布、纸白收益与阅读表面、朱红强调色形成统一尺度，保留角色茶室开场与六种情绪背景。
- 分段筛选使用单选语义，支持方向键、Home/End；窄屏仅滚动控件，当前焦点始终可见。
- 原生模态弹窗管理焦点、背景交互和页面滚动；关闭后恢复入口和位置。
- 首页、资讯列表、文章的浏览器前进后退恢复位置；资产详情返回恢复原持仓行及筛选周期。
- 收益回放结束后返回首页显示稳定结果；系统在运行中切换减少动态效果时，CSS 和 JavaScript 同时响应。
- 手选心情暂停轮换，设置可重新开启；保存过程中禁止重复选心情。收藏状态根据请求结果更新。
- 资料库支持分类、评价、项目采用、关键词筛选，以及提示词全文复制和权限不足时的手动复制。

## 自动化与浏览器验证

`npm run build` 先校验来源引用、统计、评分、分类及实际应用路径，再生成库页面与逐条 Markdown。`npm test` 的 8 项数据、持久化、通知和 HTTP 测试通过。

在本机 Chromium 浏览器的模拟视口检查界面，不等同于 iOS/Android 真机认证。

| 检查 | 结果 |
| --- | --- |
| 320、393、1280px：首页、心情、收益、资讯、文章、设置，共 18 个状态 | axe WCAG 2 A/AA 与 2.1 A/AA 检查未发现违规；无页面错误与横向溢出 |
| 280、320、360、390、768px 关键页面 | 无横向溢出；收益滑块支持键盘和日期金额说明 |
| 浏览器后退与前进 | 列表 412px、文章 91px 的阅读位置正确恢复 |
| 弹窗关闭与打开期间的历史导航 | 保留 240px 页面位置，恢复入口焦点 |
| 资产子详情返回 | 保留 520px 列表位置、资产焦点、基金分类和近 14 天周期 |

| 最终构建的资料库 | 30 条提示词、55 条评审、5 条未核验正文的资料不显示质量评分；无页面错误，目录与来源两页 axe 检查通过 |

浏览器中的写入请求用内存状态模拟，成功、失败和延迟保存均在隔离环境检验。真实服务器更新另行检查入口、配置、收藏和静态文件校验值。

axe 只能发现部分可访问性问题。本轮没有进行屏幕阅读器人工用户测试，也没有把全部候选提示词实现为组件；目录中的「采用范围」标明真实落地部分。

## 后续复验

先执行 `npm run build`，再执行 `npm run ui:preview` 启动仅监听本机的隔离预览。它使用 `.runtime/ui-review-state`，不读取个人运行目录。

另开终端运行 `node scripts/verify-ui-browser.cjs`。脚本保留已通过的 7 组行为检查，写操作在浏览器内存处理；默认读取 `.runtime/browser/node_modules` 中的 Playwright，可用 `UI_BROWSER_MODULES` 和 `UI_BROWSER_PATH` 指定已有运行库与浏览器。用 `--help` 查看配置。

构建校验器还通过了 12 个错误数据反例，包括重复 ID、无效评分、虚构来源引用、未读资料推荐、失真统计、路径越界、带凭据 URL，以及缺少验收项或实施细节。
