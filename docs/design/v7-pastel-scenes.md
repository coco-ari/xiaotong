# 首页轻插画背景与排版更新

日期：2026-10-13。

原来的繁复室内背景与人物、文案同时争夺注意力，手机短句还会被拆成不自然的字行。本轮保留小彤的六套人物素材和模块规则，用柔和色块、纸张肌理、边缘玫瑰与少量情绪物件承托人物。

## 素材与构图

六张背景均使用内置 image_gen 生成，不包含人物、文字或界面。PNG 原图为 1254 × 1254，保存于 `src/home/art/scene-pastel-*-v7.png`；对应 WebP 只做格式转换与压缩，单张约 38–62 KiB。完整提示词见 [v7-pastel-prompts.json](v7-pastel-prompts.json)。

| 场景 | 光色与边缘元素 |
| --- | --- |
| 暖阳问候 | 奶油纸色、杏色日光、浅玫瑰色块 |
| 暖阳庆祝 | 柔和暖黄、珊瑚粉、少量金色亮点 |
| 雨后陪伴 | 灰绿光色、淡粉、边缘雨滴 |
| 来信惊喜 | 杏色光色、花瓣粉、小信封 |
| 安静书香 | 鼠尾草绿、米白书本、玫瑰枝 |
| 月色晚安 | 暖灰紫、奶油月光、少量星光 |

背景文件以版本命名，当前映射统一登记在 `shared/scene-assets.mjs`。角色、背景仍可在模块设置中独立搭配，原有模块标识和用户配置无需迁移。

文案从卡片左侧 8%、顶部 19% 开始，使用 44% 宽的安全区；模块名作为上方小字。右侧人物略微缩小，移除浮尘与背景持续缩放。底部统计条叠放在封面上，采用奶油纸色和细分隔线，与收益卡保持一致。

短文案先保留完整语句分行，较长文案按中文词语与金额整体换行。延续最多 28 字、4 行、最小 16px 的约束，字号上限为 44px；放不下时明确省略。晚安背景对应浅色文字，其他场景使用暖棕或灰绿文字。

## 验证

- `npm run build`、`npm test`（50 项）、`npm run ui:check` 通过。
- Chromium 的 320、393、768px 与 WebKit 的 393px，各检查六种人物背景，共 24 个组合：无横向溢出、无文案裁切、单个前景人物，短句分行完整。
- 320、393px 各检查盈利、亏损、超长文案、四段文案、接口失败默认场景：正负金额保持完整、文案限制生效，axe WCAG 2 A/AA 与 2.1 A/AA 检查未发现违规。
- WebKit 与 Chromium 触摸打开预览、关闭、进入详情再返回：主容器和弹窗定位标题不产生整页焦点边框；键盘按钮焦点仍然可见。

截图和详细浏览器报告保存在本地 `.runtime/pastel-qa`、`.runtime/mobile-focus-qa`。这些为浏览器模拟视口验证，不替代 iPhone 真机验收。
