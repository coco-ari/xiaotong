# 首页设计约定

- 角色名为“小彤”。
- 首页从人物场景直接开始，不添加品牌栏、英文标语、头像、铃铛、欢迎标题、分类标签或底部导航。
- 用户通过纵向滑动找到卡片，点击卡片进入详情；返回时保留首页浏览位置。
- 卡片以实际内容为主：金额、趋势、文章标题、待办。避免插件宣传名、装饰图标、英文副标题、重复说明和重播按钮。
- 只保留区分数据含义所需的短标签；演示数据必须有小号、明确的演示标记。
- 收益数字优先于背景曲线，盈利红色、亏损绿色。逐日回放时数字滚动，结束后累计数缩小左移，再出现今日收益。
- 小彤切换采用旧人物退出、背景过渡、新人物与文字错峰入场的顺序；资源准备完成后才切换，禁止人物重影或加载空白。
- 背景、光线与文字颜色应对应心情；使用温和的缓动，遵循系统减少动态效果设置。
- Git 提交标题和正文使用中文。
